# API Gateway

Composant central qui sert de point d'entrée unique pour les requêtes vers les microservices AgriLink.

### Fonctionnalités principales
- Routage des requêtes vers les microservices.
- Gestion du point d'entrée de l'application.
- Centralisation des accès aux services.
- Intégration avec le mécanisme de sécurité.

### Technologies
- Java
- Spring Boot
- Spring Cloud Gateway
