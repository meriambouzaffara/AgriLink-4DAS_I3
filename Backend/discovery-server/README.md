# Discovery Server

Composant responsable de la découverte et de l'enregistrement des microservices dans l'architecture AgriLink.

### Fonctionnalités principales
- Enregistrement des microservices.
- Découverte des services disponibles.
- Localisation dynamique des microservices.
- Facilitation de la communication entre les services.

### Technologies
- Java
- Spring Boot
- Netflix Eureka
