# Harvest & Inventory Management Service

Microservice responsable de la gestion des récoltes et des stocks agricoles.

### Fonctionnalités principales
- Gestion des récoltes.
- Suivi des quantités disponibles.
- Mise à jour des stocks.
- Gestion des entrées et sorties de stock.

### Technologies
- Java
- Spring Boot
- MySQL
