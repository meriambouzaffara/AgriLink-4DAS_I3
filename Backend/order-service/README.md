# Order Management Service

Microservice responsable de la gestion des commandes entre les clients et les producteurs.

### Fonctionnalités principales
- Création des commandes.
- Consultation des commandes.
- Modification et annulation des commandes.
- Suivi du statut des commandes.
- Communication avec les services de paiement et de livraison.

### Technologies
- Java
- Spring Boot
- MySQL / H2
